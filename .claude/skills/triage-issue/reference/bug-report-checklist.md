# Bug report checklist (from JabRef's bug form)

Required:
1. JabRef version (release or development build)
2. Operating system
3. Confirmation it was tested on the latest development build
4. Steps to reproduce: numbered steps a stranger can follow
   (the placeholder "1. ... 2. ... 3. ..." does not count)

Helpful: a log excerpt, screenshot or `.bib` excerpt in the Appendix.

A report is incomplete if a required item is missing or still contains placeholder text.
