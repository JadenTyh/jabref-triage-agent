### Appendix

Exporting a library to Hayagriva YAML fails whenever the library contains a `@performance` entry, and the whole export aborts. The exporter maps the entry type through `StandardEntryType.valueOf("Performance")`, but that enum has no `Performance` constant, so a single `@performance` entry blocks an otherwise normal library export.

The export should complete, with the entry written as `type: performance`. Hayagriva's format defines `performance` as a valid entry type, a live artistic performance, and `@performance` is also a type in BibLaTeX's data model, so this is a straightforward mapping — not a crash, and not a silent conversion to `misc`.

The same crash was reproduced in 5.15, in 6.0-beta.1, and in the latest development build on 28 October 2026, in a fresh two-entry test library containing only one `@performance` entry and one ordinary `@article` entry.
